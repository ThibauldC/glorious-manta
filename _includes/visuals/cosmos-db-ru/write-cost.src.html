Cosmos DB · write work

Store the item, maintain its index

An indexed term associates a path and value with an item. Change the value and Cosmos DB updates that entry.

Create adds the document and its entries

The picture shows two entries from a shortened item. Nested fields and arrays can add entries. These labels simplify the index format.

Replace sends the full new document

Send the complete replacement, including fields you want to keep. Use an ETag condition when you must prevent overwriting another writer's changes.

Patch sends the changed paths

Replace and patch show alternative updates to the original item. The Python call requires write permission and changes stored data.

These published examples use a 1 KB document, not the shortened JSON above. Create: 5 + 10 × 0.2 = 7 RU. Replace: 5 + 5 + 2 × 0.2 + 2 × 0.2 = 10.8 RU. Patch adds 2 × 0.4 = 0.8 RU in this model. Measure your own charges.
